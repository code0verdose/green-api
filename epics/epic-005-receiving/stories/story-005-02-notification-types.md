# STORY-005-02 — Разбор типов уведомлений

**Как** оператор **хочу** видеть в чате всё, что происходит в переписке,
**чтобы** лента совпадала с телефоном.

## Таблица разбора

| `typeWebhook`                                     | Что делаем                                                                    |
| ------------------------------------------------- | ----------------------------------------------------------------------------- |
| `incomingMessageReceived` + `textMessage`         | входящее, текст `textMessageData.textMessage`                                 |
| `incomingMessageReceived` + `extendedTextMessage` | входящее, текст `extendedTextMessageData.text`                                |
| `incomingMessageReceived` + другой тип            | входящее-заглушка «Сообщение этого типа не поддерживается»                    |
| `outgoingMessageReceived`                         | исходящее, отправленное с телефона; статус `sent`                             |
| `outgoingAPIMessageReceived`                      | исходящее через API; если `idMessage` уже есть (наше) — игнор, иначе добавить |
| `outgoingMessageStatus`                           | обновить статус по `idMessage` (без отката назад)                             |
| `stateInstanceChanged`                            | обновить состояние инстанса в кеше запросов                                   |
| `quotaExceeded`                                   | баннер с описанием лимита тарифа                                              |
| групповой чат (`chatType` ≠ `user`)               | пропустить — группы вне скоупа                                                |
| неизвестный тип / невалидное тело                 | пропустить и удалить из очереди (очередь не должна заклинивать)               |

Каждое тело уведомления проходит Zod-схему (`safeParse`): дрейф формата API не роняет приложение.

## Acceptance

- **Given** `incomingMessageReceived` с текстом, **then** входящее в чате `senderData.chatId`.
- **Given** одно и то же уведомление пришло дважды, **then** сообщение в ленте одно.
- **Given** `chatName` / `senderName` в уведомлении, **then** заголовок чата обновился с номера на имя.

## DoD

Юнит-тесты маппера на каждый тип (фикстуры — примеры из документации), зелёный гейт.
