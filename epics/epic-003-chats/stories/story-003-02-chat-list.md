# STORY-003-02 — Список чатов

**Как** оператор **хочу** видеть все переписки с последним сообщением и счётчиком непрочитанных,
**чтобы** понимать, кому ответить в первую очередь.

## Acceptance

- **Given** несколько чатов, **then** сортировка по времени последнего сообщения, новые сверху.
- **Given** входящее в неоткрытый чат, **then** счётчик непрочитанных +1, чат поднимается наверх.
- **Given** открываю чат, **then** счётчик обнуляется.
- **Given** чатов нет, **then** пустое состояние с кнопкой «Новый чат».
- **Given** время сообщения сегодня — `14:05`; вчера — «вчера»; раньше — `05.10.26`.

## Tasks

- [x] Селекторы стора: отсортированный список, превью, непрочитанные.
- [x] Компоненты `chat-list`, `chat-list-item`, `chat-avatar` (инициалы, цвет по `chatId` из палитры аватарок MAX).
- [x] Ссылки — `Link` TanStack Router, `aria-current` у активного.

## DoD

Тесты селекторов и форматирования времени, компонентный тест списка, зелёный гейт.
