# STORY-003-01 — Создание чата по номеру телефона

**Как** оператор **хочу** ввести номер собеседника и сразу попасть в чат с ним,
**чтобы** начать переписку за один шаг.

## Факты из документации GREEN-API (`CheckAccount`)

- `POST {apiUrl}/waInstance{id}/checkAccount/{token}`, тело `{ "phoneNumber": 79991234567 }` (число).
- Ответ `{ "exist": true, "chatId": "10000000" }` или `{ "exist": false, "chatId": "" }`.
- MAX: только номера РФ (`7…`, 11 цифр) и РБ (`375…`, 12 цифр).
- Telegram: номер **или** `username` (`"@username"`); номер может быть скрыт настройками приватности → `exist: false`.
- Лимит 10 запросов/с; частые проверки → 469 «limit reached», мессенджер может ограничить аккаунт.
  Поэтому проверка выполняется **только по явному действию**, без автопроверки при вводе.

## Нормализация номера

`+7 (999) 123-45-67` → `79991234567`; `8 999 123 45 67` (11 цифр, начинается с 8) → `79991234567`.

## Acceptance

- **Given** MAX и номер `+7 999 123-45-67`, **when** «Создать», **then** `CheckAccount(79991234567)`, чат открыт.
- **Given** MAX и номер `+1 202 555 0100`, **when** «Создать», **then** ошибка поля «MAX: только номера РФ (+7) и Беларуси (+375)», запроса нет.
- **Given** Telegram и `@durov`, **when** «Создать», **then** `CheckAccount({ username: "@durov" })`.
- **Given** `exist: false`, **then** ошибка «У номера нет аккаунта Telegram или он скрыт настройками приватности».
- **Given** такой `chatId` уже есть, **then** открывается существующий чат.
- **Given** 466/469, **then** понятное сообщение о лимите.
