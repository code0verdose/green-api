# EPIC-003 — Чаты

## Зачем

ТЗ: «Пользователь вводит номер телефона получателя и создаёт новый чат». В MAX и Telegram
сообщения адресуются по `chatId`, а не по номеру; ответ собеседника приходит с числовым `chatId`
(`"10000000"`). Если создать чат по `79991234567@c.us`, ответ не «склеится» с ним. Поэтому номер
сначала превращается в `chatId` методом `CheckAccount` (ADR-0005).

## Scope

**In:** создание чата по номеру (Telegram — ещё и по `@username`), список чатов (превью, время,
непрочитанные, сортировка), окно чата (шапка, лента с разделителями дат), мобильная раскладка,
хранение истории в браузере.

**Out:** групповые чаты, поиск, архив, удаление чата, аватарки с сервера.

## Acceptance

- Ввожу номер → чат появляется в списке и открывается.
- У номера нет аккаунта → «У номера нет аккаунта MAX/Telegram», чат не создаётся.
- Повторный ввод того же номера открывает существующий чат, дубля нет.
- На ширине < 768 px видно либо список, либо чат; в чате есть кнопка «назад».
