# STORY-002-02 — Проверка инстанса и понятные ошибки

**Как** оператор **хочу** сразу узнать, что не так с инстансом,
**чтобы** исправить это в личном кабинете, а не писать в поддержку.

## Поведение

`GET {apiUrl}/waInstance{idInstance}/getStateInstance/{apiTokenInstance}` →
`{ "stateInstance": "authorized" | "notAuthorized" | "blocked" | "starting" | "suspended" | "pendingPassword" }`.

| Ответ                 | Что видит пользователь                                      | Вход |
| --------------------- | ----------------------------------------------------------- | ---- |
| 200 `authorized`      | —                                                           | да   |
| 200 `suspended`       | предупреждение: «отправка только контактам»                 | да   |
| 200 `notAuthorized`   | «Инстанс не авторизован: отсканируйте QR в личном кабинете» | нет  |
| 200 `starting`        | «Инстанс запускается, повторите через пару минут»           | нет  |
| 200 `blocked`         | «Аккаунт мессенджера заблокирован»                          | нет  |
| 200 `pendingPassword` | «Завершите авторизацию: нужен пароль 2FA»                   | нет  |
| 401 / 403             | «Неверный idInstance или apiTokenInstance»                  | нет  |
| 429                   | «Слишком много запросов, повторите позже»                   | нет  |
| сеть / таймаут        | «Нет связи с GREEN-API. Проверьте apiUrl и интернет»        | нет  |

## Acceptance

- **Given** корректные данные и `authorized`, **when** «Войти», **then** открывается список чатов.
- **Given** ответ 401, **when** «Войти», **then** ошибка под формой, поля сохранены.
- **Given** запрос в полёте, **when** жду, **then** кнопка в состоянии `loading`, повторный клик не шлёт запрос.
