# STORY-002-01 — Форма учётных данных с валидацией

**Как** оператор **хочу** ввести данные инстанса и сразу видеть ошибки в полях,
**чтобы** не гадать, почему вход не проходит.

## Правила полей

| Поле               | Правило                                                                                                           | Источник                                                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Мессенджер         | `max` или `telegram`                                                                                              | решение владельца                                                                                                                   |
| `idInstance`       | только цифры, до 20 знаков (пробелы по краям обрезаются)                                                          | тип uint64 в формате уведомлений GREEN-API; ровно 10 знаков не требуем — в примерах документации есть и девятизначные (`310000001`) |
| `apiTokenInstance` | латинские буквы, цифры, `-` и `_` (идёт в путь запроса)                                                           | —                                                                                                                                   |
| `apiUrl`           | `https://`, поддомен `green-api.com` или `greenapi.com`, без порта; путь допустим (`/v3`), логин/query/hash — нет | раздел «Выполнение запросов»; белый список защищает токен от отправки на чужой хост                                                 |

## Acceptance

- **Given** пустая форма, **when** нажимаю «Войти», **then** под каждым полем — текст ошибки,
  запросов в сеть нет.
- **Given** `idInstance = "41 0000 0000"`, **when** отправляю, **then** ошибка «только цифры».
- **Given** `apiUrl = "https://evil.example.com"`, **when** отправляю, **then** ошибка
  «Укажите адрес GREEN-API из личного кабинета…».
- **Given** поле токена, **when** ввожу, **then** символы скрыты; есть кнопка «показать».
