# STORY-001-04 — Публикация на сервере и домене владельца

**Как** ревьюер **хочу** открыть приложение по ссылке,
**чтобы** посмотреть его без локального запуска (пункт 4 «Результата» ТЗ, «желательно»).

## Ограничения

- Только **отдельный origin** (свой домен или поддомен): на общем `*.github.io` хранилище браузера
  общее с чужими сайтами (ADR-0004, «Хостинг»).
- Сборка — `pnpm build` (для подпути — `VITE_BASE_PATH=/путь/`), раздача `dist/` с SPA-fallback на
  `index.html` и HTTPS.
- Публикация — только после зелёного CI.

## Блокер

Данные сервера и домен от владельца.

## DoD

Ссылка в README открывает приложение; прямой заход на `/chats/<id>` не даёт 404 сервера.
