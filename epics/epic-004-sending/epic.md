# EPIC-004 — Отправка сообщений

## Зачем

ТЗ: «Пользователь пишет текстовое сообщение и отправляет его получателю в MAX»; «отправку
сообщений реализовать методом SendMessage».

## Scope

**In:** поле ввода с автоподстройкой высоты, Enter — отправить, Shift+Enter — перенос строки,
лимит длины по мессенджеру, оптимистичное появление сообщения, статусы
`pending → sent → delivered → read` и `failed` с повтором.

**Out:** цитирование (`quotedMessageId`), индикатор «печатает» (`typingTime`), превью ссылок.

## Acceptance

- Сообщение появляется в ленте сразу со статусом «отправляется».
- Ответ `{ idMessage }` → статус «отправлено»; уведомления `outgoingMessageStatus` → «доставлено»/«прочитано».
- Ошибка сети → статус «не отправлено» и кнопка «повторить»; текст не теряется.
- Пустое сообщение или только пробелы отправить нельзя.
