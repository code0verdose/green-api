# ADR-0002 — Две версии (MAX и Telegram) в одной кодовой базе

- **Статус:** принято
- **Дата:** 2026-10-05

## Контекст

ТЗ требует MAX (запасной вариант — WhatsApp или Telegram). У владельца нет MAX-аккаунта для
живой проверки, есть Telegram. Решение владельца: «сделаем 2 версии, MAX и TG».

Сверка документации GREEN-API (`/v3/docs` для MAX и `/telegram/docs`) показала, что API почти
идентичен: те же пути `{apiUrl}/waInstance{id}/{method}/{token}`, те же методы и формат
уведомлений. Отличия:

| Что                         | MAX (v3)                                         | Telegram                         |
| --------------------------- | ------------------------------------------------ | -------------------------------- |
| Лимит длины `SendMessage`   | 4000 символов                                    | 4096 символов                    |
| `CheckAccount`              | только `phoneNumber`, номера РФ (7…) и РБ (375…) | `phoneNumber` **или** `username` |
| Пример хоста в документации | `3100.api.green-api.com`                         | `4100.api.green-api.com`         |
| Статус `notInGroup`         | есть                                             | нет                              |
| Прототип интерфейса         | web.max.ru                                       | web.telegram.org                 |

## Решение

Одна кодовая база, мессенджер — параметр сессии (`Session.messenger`), выбирается на экране входа.
Все различия собраны в трёх местах:

1. **Данные:** `src/shared/config/messengers.constant.ts` — лимиты, хосты по умолчанию, ссылки.
2. **Правила адресата:** `src/units/chat/model/validation/recipient.schema.ts` — схема на мессенджер.
3. **Внешний вид:** токены `--gac-*` в `src/app/styles/global.css` на `<html data-messenger>`,
   палитра Mantine — в `src/app/theme/mantine-theme.config.ts`.

Код запросов, поллер, разбор уведомлений, стор и UI — общие.

## Альтернативы

- **Две сборки / две ветки** — дублирование кода и багов, отвергнуто.
- **Абстрактный «адаптер мессенджера» с интерфейсом** — избыточен: различия сводятся к данным,
  а не к поведению. Если появится мессенджер с другим API — тогда вводится адаптер.

## Последствия

- Добавить WhatsApp = запись в `MESSENGERS`, схема адресата и набор токенов.
- Тесты разбора уведомлений используют фикстуры из документации обоих мессенджеров.
