# Roadmap

Порядок работ и зависимости. Сроков нет намеренно.

## MVP — тестовое задание (текущая версия)

Порядок: платформа → вход → чаты → отправка → получение → сдача.

| Шаг | Эпик                                                                    | Зависит от                         |
| --- | ----------------------------------------------------------------------- | ---------------------------------- |
| 1   | [EPIC-001 Платформа и темы](../../epics/epic-001-platform/epic.md)      | —                                  |
| 2   | [EPIC-002 Вход по учётным данным](../../epics/epic-002-session/epic.md) | EPIC-001                           |
| 3   | [EPIC-003 Чаты](../../epics/epic-003-chats/epic.md)                     | EPIC-002                           |
| 4   | [EPIC-004 Отправка сообщений](../../epics/epic-004-sending/epic.md)     | EPIC-003                           |
| 5   | [EPIC-005 Получение сообщений](../../epics/epic-005-receiving/epic.md)  | EPIC-003; статусы — после EPIC-004 |
| 6   | [EPIC-006 Сдача](../../epics/epic-006-delivery/epic.md)                 | все выше                           |

Узкое место — живая проверка: нужен авторизованный инстанс. MAX-инстанса у владельца нет,
поэтому живой прогон делается на Telegram, а MAX проверяется e2e-тестами на моках по
документации GREEN-API.

Публикация (STORY-001-04) ждёт сервер и домен владельца; до неё — локальный запуск по README.

## v1 — если проект живёт дальше

- Медиа: изображения и документы (`SendFileByUpload`, `DownloadFile`).
- История с сервера (`GetChatHistory`) при открытии чата.
- Отметка прочтения (`ReadChat`) при открытии чата.
- Тёмная тема для обеих версий: токены у MAX и Telegram уже есть.
- Индикатор «печатает» (`SendTyping`).

## Later

- Свой бэкенд-прокси: токен не уходит в браузер, уведомления по webhook.
- WhatsApp как третий мессенджер: архитектура адаптеров это позволяет.
- PWA и системные уведомления о новых сообщениях.
