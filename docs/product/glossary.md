# Глоссарий (ubiquitous language)

Термины ниже — единый язык документов и кода. Имена юнитов, сущностей, типов и схем в `src/`
берутся отсюда.

| Термин                         | В коде                                          | Определение                                                                                                                                                     |
| ------------------------------ | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Мессенджер**                 | `Messenger` = `'max' \| 'telegram'`             | Мессенджер, с которым работает инстанс. Определяет тему оформления, лимит длины сообщения и правила номера телефона.                                            |
| **Инстанс**                    | —                                               | Шлюз GREEN-API, привязанный к одному аккаунту мессенджера (одному номеру телефона).                                                                             |
| **idInstance**                 | `idInstance`                                    | Уникальный номер инстанса (только цифры). Берётся из личного кабинета GREEN-API.                                                                                |
| **apiTokenInstance**           | `apiTokenInstance`                              | Ключ доступа к инстансу. Секрет: хранится только в `sessionStorage` вкладки, в логи и HTTP-кеш не попадает.                                                     |
| **apiUrl**                     | `apiUrl`                                        | Хост API инстанса, например `https://4100.api.green-api.com`. Берётся из личного кабинета, по `idInstance` не вычисляется.                                      |
| **Учётные данные**             | `GreenApiCredentials` + `Session`               | Набор `messenger + idInstance + apiTokenInstance + apiUrl`, которого достаточно для вызова API.                                                                 |
| **Сессия**                     | `Session` (юнит `session`)                      | Состояние «пользователь вошёл»: учётные данные лежат в хранилище, инстанс проверен.                                                                             |
| **Состояние инстанса**         | `InstanceState`                                 | Значение `stateInstance`: `authorized`, `notAuthorized`, `blocked`, `starting`, `suspended`, `pendingPassword`.                                                 |
| **Чат**                        | `Chat` (юнит `chat`)                            | Переписка с одним собеседником. Ключ — `chatId`.                                                                                                                |
| **chatId**                     | `Chat.id`, `Message.chatId`                     | Идентификатор чата в мессенджере, например `10000000`. Получается методом `CheckAccount`.                                                                       |
| **Собеседник**                 | `Chat.title`, `Chat.phone`, `Chat.username`     | Человек на другой стороне чата. Имя приходит в уведомлениях (`senderName`/`chatName`).                                                                          |
| **Сообщение**                  | `Message`                                       | Текстовое сообщение в чате.                                                                                                                                     |
| **Входящее / исходящее**       | `MessageDirection` = `'incoming' \| 'outgoing'` | Направление сообщения относительно владельца инстанса.                                                                                                          |
| **idMessage**                  | `Message.idMessage`                             | Идентификатор сообщения в GREEN-API. Приходит в ответе `SendMessage` и в уведомлениях; по нему сообщения не дублируются.                                        |
| **Ревизия**                    | `Message.rev`                                   | Счётчик изменений статуса сообщения на этом клиенте. При слиянии истории вкладок побеждает копия с большей ревизией (ADR-0004).                                 |
| **Статус сообщения**           | `MessageStatus`                                 | `pending` (отправляется) → `sent` (принято API) → `delivered` → `read`; либо `failed` (не ушло, можно повторить).                                               |
| **Неподдерживаемое сообщение** | `Message.kind = 'unsupported'`                  | Входящее не текстовое сообщение (фото, стикер и т. п.). Показывается заглушкой.                                                                                 |
| **Уведомление**                | `NotificationEvent` (юнит `notification`)       | Событие из очереди GREEN-API (входящее, исходящее, статус, состояние инстанса, квота), разобранное в доменное событие; мост в `pages/chats` раздаёт его юнитам. |
| **Тип уведомления**            | `typeWebhook`                                   | `incomingMessageReceived`, `outgoingMessageReceived`, `outgoingAPIMessageReceived`, `outgoingMessageStatus`, `stateInstanceChanged`, `quotaExceeded`.           |
| **receiptId**                  | `receiptId`                                     | Номер доставки уведомления; нужен, чтобы удалить его из очереди методом `DeleteNotification`.                                                                   |
| **Очередь уведомлений**        | —                                               | FIFO-очередь инстанса на стороне GREEN-API, уведомления живут в ней 24 часа.                                                                                    |
| **Поллер**                     | `NotificationPoller`                            | Цикл `ReceiveNotification → обработка → DeleteNotification`. В каждый момент на инстанс работает один — в одной из вкладок.                                     |
